#NoteSphere - 2210990164_2210990157

## Project Overview
NoteSphere is a full stack note-sharing platform where users can create accounts, publish, save and rate notes across various domains such as Mathematics, Science, Literature, Arts, History and Philosophy.

## Features
- User authentication and account creation
- Create and publish notes
- Save notes for future reference
- Rate notes uploaded by other users
- Categorized notes by subject/domain
- Responsive full stack web application

## Technologies Used
- Frontend: React.js / HTML / CSS / JavaScript
- Backend: Node.js / Express.js
- Database: MongoDB
- Authentication: JWT / Session based authentication
